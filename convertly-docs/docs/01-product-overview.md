# 01 — Visão Geral do Produto

## Nome

**Convertly**

## Descrição

Convertly é um SaaS freemium para conversão de arquivos. Usuários autenticados podem enviar documentos, converter arquivos para formatos suportados e acompanhar o histórico dentro de um dashboard.

## Conversão inicial

```txt
DOCX -> PDF
```

## Público-alvo

- estudantes;
- freelancers;
- profissionais administrativos;
- pequenas empresas;
- pessoas que precisam converter documentos ocasionalmente.

## Problema

Ferramentas de conversão online normalmente têm:

- interface poluída;
- anúncios;
- limites pouco claros;
- baixa confiança;
- processo confuso;
- ausência de histórico.

## Solução

O Convertly oferece:

- conta de usuário;
- dashboard pessoal;
- limite mensal claro;
- histórico de conversões;
- download seguro;
- planos simples;
- interface limpa.

## Modelo SaaS

Planos:

- Free: 5 conversões/mês;
- Pro: 100 conversões/mês;
- Business: 500 conversões/mês.

No MVP, o upgrade é simulado.

## Deploy oficial

O projeto será publicado com serviços gratuitos:

```txt
Frontend: Vercel
Backend/API + Worker: Koyeb Docker
Database: Supabase PostgreSQL
Storage: Supabase Storage
```

## Valor para portfólio

Este projeto demonstra:

- React + TypeScript;
- C#/.NET;
- SaaS freemium;
- autenticação;
- regras de plano;
- upload e storage externo;
- processamento assíncrono;
- Docker;
- deploy real;
- documentação técnica.

## Fora do MVP

Não entra no MVP:

- pagamento real;
- OCR;
- PDF para DOCX;
- upload em lote;
- painel admin;
- notificações por e-mail;
- app mobile.
